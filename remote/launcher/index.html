ℹ️ Como usar

📊 Dashboard — abre o painel IoT em tela cheia. Troque a URL em Ajustes.
📺 Vídeo — YouTube e esportes. Toque num canal ao vivo (Cazé etc) ou busque. Usa H.264 até 1080p com decode por hardware.
🎵 Música — Spotify. No celular, escolha TV LASDPC em Conectar dispositivo.
🎮 Jogo — emulador (Zelda OoT e outros N64). Movimento nas setas; A=X, B=Z, trava-alvo=Shift, pausa=Enter. Um controle USB funciona automaticamente.
🖥️ Desktop — ambiente gráfico normal.
Sair de qualquer app: tecla Super+Esc (Windows+Esc) volta a este menu.
Admin remoto: ssh lasdpc@10.0.1.218 (LAN) ou via Tailscale. Em travamento, use Energia → Reiniciar.
Navegue com ←→↑↓ ou controle • Enter seleciona • Super+Esc volta ao menu
