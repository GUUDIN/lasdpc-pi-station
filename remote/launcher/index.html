ℹ️ Como usar

📊 Dashboard — abre o painel IoT em tela cheia. Troque a URL em Ajustes.
📺 YouTube — interface de TV do YouTube, sem anúncios, 1080p com decodificação por hardware. Navegue com setas, Enter e Esc (voltar). Para mandar vídeos do celular: no YouTube da TV, Configurações → Vincular com código de TV; no app do celular, digite o código e use Transmitir. Para sair: Super+Esc ou o botão ← Menu (mexa o mouse).
🎵 Música — Spotify. No celular, escolha TV LASDPC em Conectar dispositivo.
🎮 Jogo — escolha o jogo na lista; uma tela de carregamento mostra o progresso até o jogo abrir. Movimento nas setas; A=X, B=Z, trava-alvo (Z)=Shift, escudo (R)=V, botões C=I J K L, pausa=Enter, menu do jogo=F1. Um controle USB funciona automaticamente.
🖥️ Desktop — ambiente gráfico normal.
Neste menu: mouse, setas/Tab + Enter, ou controle (direcional + A). Esc, Backspace ou B fecham a janela aberta.
Sair de qualquer app: tecla Super+Esc (Windows+Esc) volta a este menu.
Admin remoto: ssh lasdpc@10.0.1.218 (LAN) ou via Tailscale. Em travamento, use Energia → Reiniciar.
←→↑↓, mouse ou controle • Enter seleciona • Esc fecha • Super+Esc volta ao menu
